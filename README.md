# 📊 Adventure Works Sales Analysis

## 📌 Project Overview

Adventure Works Sales Analysis is a Business Intelligence project focused on transforming raw sales data into actionable insights. Using SQL and Power BI, the project analyzes sales performance, customer behavior, product trends, and regional performance to support data-driven business decisions.

---

## 🎯 Project Objectives

✔️ Analyze overall sales performance

✔️ Track revenue, profit, and order trends

✔️ Identify top-selling products and categories

✔️ Understand customer purchasing behavior

✔️ Evaluate regional sales performance

✔️ Build interactive dashboards for stakeholders

---
